# Майбутні тести backend

Тестів ще немає. Папки містять лише .gitkeep, щоб зберігатися в Git.
Не створюємо порожні test_*.py, які можна помилково сприйняти за покриття.

| Папка | Що перевіряти | Власник |
|---|---|---|
| unit/ | Валідація, правила дат і статусів, обробка списків | Автор відповідного backend-модуля |
| integration/ | Реальна PostgreSQL: міграції, унікальність участі, транзакції та паралельні запити | Backend Core |
| security/ | Чужий домен, недійсна сесія, права, CSRF, відсутність витоку вибору | Backend Auth разом із QA |

Перший робочий PR додає pytest, потрібні fixtures у conftest.py та реальний
тест /health. Наступні PR додають тести разом із функціями. DevOps підключає
точні команди до CI. QA готує сценарії й перевіряє результати, а розробники
відповідають за тести своєї реалізації.
