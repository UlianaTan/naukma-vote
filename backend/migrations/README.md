# Міграції бази даних

Тут будуть Alembic-міграції. Зараз це лише папка без конфігурації й міграцій.
Backend Core створює Alembic-конфігурацію, env.py і script.py.mako під час
першого налаштування SQLAlchemy. Файли версій потрапляють у versions/.

Не створювати порожні міграції як заглушки. Кожна міграція має відповідати
змінам моделей і бути перевірена на тестовій PostgreSQL. Для змін схеми
в PR описувати вплив на дані та можливість відкату. DevOps запускає міграції
на staging/production за документованим порядком; секрети не зберігаються тут.
