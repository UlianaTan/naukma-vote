# Майбутні тести frontend

Тестових сценаріїв ще немає; .gitkeep лише зберігає порожні папки в Git.

- components/ — перевірки форм, валідації, завантаження та помилок.
- e2e/ — повний шлях студента й організатора з окремими тестовими даними.
- fixtures/ — синтетичні відповіді API для тестів, без реальних email і голосів.

Frontend-розробники додають компонентні тести своїх функцій. QA і frontend
спільно готують наскрізні сценарії; DevOps автоматизує їх запуск.
Тестовий інструмент, конфігурація й команди додаються з першими справжніми тестами.
