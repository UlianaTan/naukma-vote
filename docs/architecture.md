# Будова та відповідальність

Браузер студента → React frontend → FastAPI backend → PostgreSQL.
Google підтверджує особу через OAuth; backend перевіряє токен,
домен і право конкретної людини брати участь у голосуванні.
Браузер не підключається безпосередньо до БД.

Frontend показує кнопки та сторінки. Backend вирішує, що дозволено,
приймає голоси й повертає результати. БД зберігає дані та підтримує
транзакційні гарантії. DevOps забезпечує перевірки і запуск цих частин.

| Учасник | Відповідальність |
|---|---|
| Backend Auth & Security | Google OAuth, перевірка домену, сесії, права, CSRF, rate limiting |
| Backend Elections & Voting Core | Голосування, кандидати, допуск, прийом голосу, міграції, підрахунок, аудит |
| Frontend Voter Experience | Вхід, список голосувань, вибір кандидата, підтвердження, результати |
| Frontend Admin Panel | Створення голосувань, кандидати, списки виборців, явка, результати |
| UI/UX Designer | Сценарії, макети, спільні компоненти, мобільний вигляд, зрозумілі тексти |
| QA Engineer | Тест-план, сценарії, помилки, перевірки доступу, повторного голосу й витоків |
| DevOps & Release Engineer | Репозиторій, CI/CD, середовища, секрети, деплой, координація інтеграції та релізу |

Backend-розробники пишуть тести своєї логіки, QA перевіряє сценарії й ризики,
DevOps автоматизує запуск перевірок. Backlog ведуть усі учасники.

Анонімність результатів і приховування вибору від адміністраторів БД — різні
вимоги. Схему даних, часові мітки та журнали потрібно погодити до реалізації.
Хеш userId сам по собі не гарантує анонімності. Не записуємо токени чи
зв'язок виборця з кандидатом у технічні логи.
