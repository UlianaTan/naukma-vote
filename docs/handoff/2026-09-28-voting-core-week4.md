## 1. Що зроблено в межах етапу
- Налаштовано підключення до хмарної бази даних PostgreSQL через асинхронний драйвер `asyncpg`.
- Сконфігуровано середовище міграцій Alembic та згенеровано початкову ревізію `initial_voting_core_tables` для сутностей: `users`, `elections`, `candidates`, `eligible_voters`, `voter_participations`, `ballots`.
- Реалізовано Pydantic-схеми для створення та редагування чернеток виборів з валідацією часових рамок (`start_date < end_date`, заборона встановлення дати початку в минулому).
- Створено dependency для перевірки ролі адміністратора/організатора виборів (відповідь `403 Forbidden` для неавторизованих користувачів).
- Додано REST API ендпоінти для керування чернетками виборів та кандидатами:
  - `POST /api/v1/admin/elections` (створення чернетки, `201 Created`)
  - `GET /api/v1/admin/elections` (список виборів)
  - `GET /api/v1/admin/elections/{id}` (деталі виборів)
  - `PUT /api/v1/admin/elections/{id}` (редагування чернетки)
  - `DELETE /api/v1/admin/elections/{id}` (видалення чернетки)
  - `POST /api/v1/admin/elections/{id}/candidates` (додавання кандидатів)
- Роутер підключено до головного додатку FastAPI (`backend/app/main.py`), документація доступна у Swagger UI (`/docs`).

## 2. Інструкція для QA
- **Swagger UI:** доступний за адресою `http://localhost:8000/docs`.
- **Основні кейси для тестування:**
  1. Створення виборів з валідними датами (`201 Created`).
  2. Валідація дат: спроба передати дату початку в минулому або дату завершення раніше дати початку (`422 Unprocessable Entity`).
  3. Перевірка доступу: звернення без прав адміністратора (`403 Forbidden`).
  4. Спроба редагування або додавання кандидатів до неіснуючих виборів (`404 Not Found`).
