# Виправлення огляду PR #21

Перевірка TEST_DATABASE_URL використовує розібрану назву БД, а не query
або пароль. Тести ізольовані в випадкових схемах і не видаляють public
таблиці. Адміністратор flush-иться перед створенням виборів.

Явка рахує whitelist, участі та бюлетені одним SQL statement snapshot.
Додано регресійний тест interleaving та PostgreSQL-тест явки під час
паралельних голосів. Backend CI піднімає PostgreSQL 16 і перевіряє
upgrade head та відповідність схеми моделям через alembic check.

Auth, користувацьке тестування та політика оновлення історичних CLOSED
виборів із відсутнім closed_at залишаються окремими задачами.
