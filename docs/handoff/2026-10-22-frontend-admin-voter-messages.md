## Що зроблено

У CreateElectionPage додано повідомлення без показу списку збережених адрес:

- Червона помилка біля «Виборці», якщо під час запуску фактичний список порожній.
- Червона помилка з причинами від backend для некоректних адрес або чужого домену,
  як для ручного введення, так і CSV/TXT. Хоча б одна відхилена адреса зупиняє
  поточну спробу запуску; коректні адреси зберігаються, некоректні лишаються в полі.
- Помилки читання файла теж відображаються поряд із розділом.
- Темно-синя підказка після збереження та при повторному відкритті чернетки,
  тільки якщо backend підтвердив хоча б одного збереженого виборця.
- Якщо перевірка збереженого списку не вдалася, показується помилка з повторною
  перевіркою; стан не підміняється «список порожній» або «виборців збережено».
- Асинхронні читання, розпочаті до нового збереження, ігноруються після cleanup.
- Додано label/htmlFor, aria-invalid, aria-describedby та role=alert для помилок.
- Чернетку без виборців і далі можна зберігати. Порожні поля не блокують запуск,
  якщо список у backend уже містить виборців.

Backend, авторизація, правила статусів/часу, імпорт і семантика запуску збережені.
Нова міграція або змінні середовища не потрібні.
