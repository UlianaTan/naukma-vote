# Підготовка staging

Staging — окремий тестовий сайт для команди. Production — сайт для користувачів.
Зараз жодне середовище не розгорнуто, провайдера не обрано.

До деплою DevOps разом із розробниками фіксує:

- хостинг frontend, backend, PostgreSQL, бюджет і власників акаунтів;
- підтримувані версії runtime, команди install/build/start;
- HTTPS-адреси, OAuth callback, frontend origin і CORS;
- секрети в налаштуваннях середовища, окремі від local;
- команду міграцій Alembic та відповідального за їх виконання;
- health endpoint, доступ до журналів і виключення чутливих даних із логів;
- порядок повернення попередньої версії й сумісність зі змінами БД;
- резервне копіювання та перевірку відновлення перед production.

Перший staging: каркаси frontend/backend, БД, міграції та OAuth.
Критерій тижня 4: реальний дозволений акаунт проходить наскрізний вхід.
Платні ресурси створюються після узгодження бюджету.
